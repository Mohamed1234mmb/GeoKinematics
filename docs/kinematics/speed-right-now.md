# SpeedRightNow
 This class tells you your Current Speed (Instant Speed) right now.

### GetSpeedRightNow

Calculates how fast you are going at this exact moment.


```csharp
example : a car moving at 20 km/h

double speed = SpeedRightNow.GetSpeedRightNow(0.01, 0.5);
Console.WiteLine(speed);
```
